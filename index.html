PERSONAL_HERMES_AGENT

A private, single-user automation client for the owner's own Google account.

What this application is

PERSONAL_HERMES_AGENT is a personal-use OAuth client. It is not a public product, it has no sign-up, and it is not distributed to other users. It exists so that one individual — its owner — can let a locally running, self-hosted assistant read and act on that same person's own Google data (Gmail, Calendar, Drive, Contacts, Sheets, Docs) on the owner's own computer.

What it does with Google data

  • Reads the owner's email to produce a morning summary and to watch for replies from specific senders.
  • Reads the owner's calendar to report the day's events.
  • Prepares and sends email only when the owner explicitly asks for it.
  • Reads or edits Drive files, Sheets and Docs only when the owner explicitly asks for it.

All processing happens on the owner's own machine. Data is never sold, and it is not shared with third parties. Google user data is not used to train models.

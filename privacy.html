1. Scope

This policy covers PERSONAL_HERMES_AGENT, a private OAuth client used by a single individual on a single self-hosted computer. It is not offered to the public and has no other users.

2. What data is accessed

With the owner's explicit consent, the application requests these Google scopes:

  • gmail.readonly, gmail.modify, gmail.send — read, label and send the owner's own email.
  • calendar — read and create the owner's own calendar events.
  • drive — read and edit the owner's own Drive files.
  • contacts.readonly — look up the owner's own contacts.
  • spreadsheets, documents — read and edit the owner's own Sheets and Docs.

Only the owner's own account is ever accessed. No other Google account is read or written.

3. Why the data is accessed

  • To summarise the owner's calendar and selected email for the owner.
  • To monitor for messages from specific senders the owner names.
  • To draft or send mail, and to read or update documents, only when the owner asks.

4. How data is stored and protected

Data is stored only on the owner's own computer, in the assistant's local configuration and session directories. OAuth credentials are stored in a file readable only by the owner's user account. No Google user data is uploaded to a third-party service, and backups, when taken, are encrypted with a key held only by the owner.

5. Sharing

No Google user data is sold, rented, transferred, or disclosed to any third party. Data is not used for advertising, and it is not used to develop, improve, or train generalised AI or machine learning models.

6. Retention and deletion

Locally cached copies are pruned automatically and can be deleted at any time by the owner. Revoking the application's access at myaccount.google.com/permissions immediately stops all further access; a fresh authorisation is then required to use the app again.

7. Google API Services User Data Policy

PERSONAL_HERMES_AGENT's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
